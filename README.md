# PDV

Punto de venta: monorepo con una aplicación React/Vite y una API Go. La
persistencia arranca en memoria y pasa a PostgreSQL en una fase posterior.

El proyecto está en construcción. El plan de la versión base está en
[docs/plans/version-base.md](docs/plans/version-base.md) y las reglas para
agentes y colaboradores en [AGENTS.md](AGENTS.md).
